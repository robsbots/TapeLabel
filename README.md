
# TapeLabel
<br>
Python script to label punched tape with human readable labels.<br>
<br>
To use :<br>
<br>
	$ ./tlabel.py -l "Your label text" -f ./output.bin<br>
<br>
Outputs a binary file containing "YOUR LABEL TEXT"<br>
( Currently only uppercase is supported )<br>
<br>
	$ ./tlabel.py -l "Your label text" -a ./output.txt<br>
<br>
Outputs a text file containing a text representaion of a tape label<br>
